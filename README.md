# Automata Studio

A fun, browser-based automata simulator built for enjoyment and to help with **COMP4141** (Theory of Computation).

## What is it?

Automata Studio lets you visually build and simulate various types of automata directly in your browser — no installation required. Just open `automata-simulator.html` and start experimenting.

### Supported automata (current & planned)

| Type | Status |
|------|--------|
| DFA (Deterministic Finite Automaton) | ✅ Available |
| NFA (Nondeterministic Finite Automaton) | 🚧 Coming soon |
| GNFA (Generalised NFA) | 🚧 Coming soon |
| PDA (Pushdown Automaton) | 🚧 Coming soon |
| Turing Machine | 🚧 Coming soon |

## How to use

1. Open `automata-simulator.html` in any modern browser.
2. Use **Add** mode to place states on the canvas.
3. Add transitions between states using the sidebar.
4. Enter an input string and hit **Run** to simulate.

## Purpose

This project is made for fun and as a personal study aid for **COMP4141** at UNSW. It's a great way to visualise automata concepts covered in the course.
